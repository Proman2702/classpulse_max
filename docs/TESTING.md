# Сценарий проверки ClassPulse

Перед проверкой: схема применена, функции развёрнуты, выполнен `npm run seed`.
Пароль всех тестовых аккаунтов: **`ClassPulse2026`**. Данные вымышленные.

| Роль | Логин |
|---|---|
| Ученик | `student@classpulse.test` |
| Учитель | `teacher@classpulse.test` |
| Психолог | `psychologist@classpulse.test` |

Где открывать: бот ClassPulse в MAX → «Открыть ClassPulse», или https://classpulse-max.vercel.app в браузере,
или `http://localhost:8080` после `docker compose up --build`.

## 1. Бот

| Шаг | Ожидаемый результат |
|---|---|
| Открыть бота в MAX, нажать «Начать» или `/start` | Приветствие и кнопка «Открыть ClassPulse» |
| `/help` | Список команд и Детский телефон доверия 8-800-2000-122 |
| Любое другое сообщение | Подсказка и кнопка открытия приложения |

## 2. Ученик: опрос дня

| Шаг | Ожидаемый результат |
|---|---|
| Войти как `student@classpulse.test` | Вкладка «Сегодня», бот пишет «Привет, Маша! Как прошёл твой день?» |
| Нажать «😕 Тяжело» | Ответ «😕 Тяжело · 2/5» справа, бот спрашивает о причинах |
| Отметить «Конфликт», «Одиночество» → «Дальше» | Выбранные причины уходят сообщением, бот предлагает комментарий |
| Написать «Поссорилась с подругой» → отправить | Индикатор «печатает», затем ответ с галочкой, бот благодарит и предлагает психолога |
| Кнопка «Записаться к психологу» | Переход во вкладку «Поддержка» |
| Вернуться в «Сегодня» → «Переголосовать» | Опрос начинается заново с сохранёнными ответами; после отправки ответ за день обновляется, а не дублируется |
| Закрыть и открыть приложение | Сессия восстановлена, показан завершённый диалог за сегодня |

## 3. Ученик: поддержка

| Шаг | Ожидаемый результат |
|---|---|
| «Записаться к психологу» → выбрать «Ольга Викторовна», тема, время → «Записаться» | Шторка закрывается, зелёное «Готово!…», запись в «Мои записи» со статусом «Ждёт ответа» |
| Отправить форму записи с пустой темой | Ошибка «Напишите пару слов о теме разговора», запрос не отправляется |
| «Анонимная жалоба» → получатель «Ольга Викторовна», «На ученика», текст → «Отправить анонимно» | «Жалоба отправлена…», жалоба в «Мои жалобы» со статусом «Новая» |
| Блок «Чат с учителем в MAX» | Анна Петровна; «Написать» активна, если учитель указал ссылку на профиль MAX |
| «Профиль» → вставить `https://max.ru/u/test` → «Сохранить» | «Сохранено»; ссылка вида `https://vk.com/...` отклоняется с понятной ошибкой |

## 4. Учитель: класс

| Шаг | Ожидаемый результат |
|---|---|
| Войти как `teacher@classpulse.test` | «Мой класс · 5 учеников», «Ответили сегодня 4 / 5» (после шага 2), средняя оценка с эмодзи |
| Список учеников (сортировка «По состоянию») | Сверху Лиза ⭐ (на контроле), затем «Требует внимания» (Маша), «Нестабильное» (Дима), «Стабильное» (Катя, сегодня «ещё не отвечал»), «Хорошее» (Артём) |
| «Составить сводку» | «Читаю ответы…», через 5–15 с — разделы «Общее настроение», «Основные темы», «Трудности»; имён в тексте нет |
| Поиск «ли» | Остаётся Лиза Орлова |
| Фильтр «⭐ На контроле» | Только Лиза |
| Сортировка «По имени» | Алфавитный порядок |
| Открыть Лизу | Состояние, последняя 2/5, средняя, комментарий «На перемене снова смеялись надо мной», причины, 5 оценок по датам, заметка учителя |
| Добавить заметку → удалить её | Заметка появляется сверху, затем исчезает |
| «На контроле» → снять | Звезда у аватара исчезает; фильтр «На контроле» пуст |
| «+» → ник «Нет такого» | Ошибка «Ученик с таким ником не найден» |
| «+» → ник уже добавленного ученика | Ошибка «Этот ученик уже в классе» |

## 5. Обращения (учитель и психолог)

| Шаг | Ожидаемый результат |
|---|---|
| Учитель → «Обращения» | Бейдж с числом новых; запись Кати «Ждёт ответа», запись Артёма «Принята» |
| Открыть запись Кати → «Принять» | Статус «Принята», бейдж на вкладке уменьшается |
| Войти как `psychologist@classpulse.test` | Записи от Лизы и Маши |
| «Жалобы» | Жалобы без имени автора; «Важно» выше «Обычная» |
| Открыть новую жалобу | Статус меняется на «Прочитана»; кнопка «Отметить решённой» → «Решена» |
| Ученик Маша → «Поддержка» | Статусы её записи и жалобы обновились |

## 6. Уведомления в MAX

Нужно: настроены секреты и `private.app_config` (см. README), учитель и психолог хотя бы раз открыли
ClassPulse из бота в MAX («Профиль» → «Уведомления в MAX: Подключены»).

| Шаг | Ожидаемый результат |
|---|---|
| Ученик ставит «😕 Тяжело» | Учителю приходит сообщение бота: «🔔 Маша отметил(а) день: 😕 Тяжело…» с кнопкой «Открыть ClassPulse» |
| Ученик записывается к психологу | Психологу — «📅 Маша записался(ась) на разговор…» |
| Психолог принимает запись | Ученику — «Твоя запись к Ольге Викторовне принята ✅» |
| Ученик отправляет жалобу | Получателю — «🛡 Новая анонимная жалоба (срочность: …)» без имени автора |
| Получатель отмечает жалобу решённой | Автору — «Твою жалобу рассмотрели…» |
| Учитель → «Класс» → «Пригласить учеников через MAX» | Открывается окно «Поделиться» MAX со ссылкой на бота; в браузере — системное меню или копирование |

## 7. Ошибки и устойчивость

| Ситуация | Ожидаемый результат |
|---|---|
| Неверный пароль | «Неверный email или пароль» |
| Нет сети при отправке опроса | Баннер «Нет соединения…», ответ не теряется, можно отправить повторно |
| GigaChat недоступен | Сводка: сообщение об ошибке, повтор той же кнопкой; жалоба отправляется со срочностью «Обычная» |
| Системная кнопка «Назад» в MAX при открытой шторке | Шторка закрывается |
| Тёмная тема устройства | Интерфейс переключается автоматически |

## 8. Проверка анонимности (для технической комиссии)

В Supabase SQL Editor, от имени получателя жалобы:

```sql
set role authenticated;
set request.jwt.claims = '{"sub":"<auth id психолога>"}';
select author_id from public.reports;   -- ERROR: permission denied for table reports
select message from public.reports;     -- жалобы видны
```
